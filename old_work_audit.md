## 3. Проверка внутренней согласованности Таблицы 1

Скрипт: `src/audit/table1_consistency.py` → `results/tables/old_table1_consistency.csv`.
Исходные данные скрипта — только числа самой статьи (N = 3 474, 278 положительных).

1. **Precision не согласуется с FPR.** Из Recall и FPR для SVD получается TP ≈ 243, FP ≈ 150, то есть Precision ≈ **0,618** (в таблице 0,894). Наоборот: из Precision 0,894 и Recall 0,873 следует FPR ≈ **0,009** (в таблице 0,047). Для IF, OC-SVM, LOF расхождения того же рода (implied precision 0,53 / 0,57 / 0,50 против 0,76 / 0,79 / 0,74).
2. **Порог P95 несовместим с Recall.** Если τ — 95-й процентиль ошибок, помечено не более 5 % аккаунтов ≈ 174, а положительных 278; максимальная достижимая полнота ≈ **0,625**, заявлена 0,873.
3. Арифметика F1 по P и R, разности F1/AUC в тексте и отношение времён обучения (≈ 5,0–13,5) — внутри себя сходятся; это не доказывает корректность самих измерений.

Вывод: хотя бы одно из чисел Таблицы 1 или описание правила порога ошибочно; **эксперимент не воспроизводим и не может использоваться как доказательство**. Причина расхождения не установлена (возможные: другой порог/оценка, ошибка при подсчёте FPR, смена выборки между версиями). Требуется запрос к авторам исходных логов.

## 4. Прочие замечания к тексту, влияющие на новую работу

- «Нелегитимные аккаунты» в названии и аннотации — метки датасета означают spam/bot/fake follower.
- Статистика во введении (ПроДокторов 85 000 отзывов/мес, 350 тыс. отклонённых отзывов в 2025 г., 22–29 % ботов, 66 %, 28,9 %, ущерб 50–300 млн долл./день) приведена со ссылками, но **не перепроверена** в этом аудите — проверять по первоисточникам при написании новой статьи.
- Ссылка [17] (DDoS, CP-разложение) использована как «близкая по методологии» — по теме не относится; [14]–[16], [18] косвенны.
- Ссылка [11] (Huang & Kasiviswanathan, VLDB 2016) — по сути ближайший предшественник идеи «ошибка реконструкции относительно поточного низкорангового базиса»; её присутствие в списке опровергает тезис «впервые».
- Текст сообщает «ограничение: adversarial-стратегии» и «вне рассмотрения коллективная согласованность» — оба пункта входят в новую постановку.
