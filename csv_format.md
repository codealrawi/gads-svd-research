# Формат CSV для загрузки

Пример: `src/ui/static/example_synthetic.csv` (синтетический, 250 аккаунтов × 26 окон; также доступен по кнопке «Скачать пример CSV» в интерфейсе).

## Структура

Длинный формат: **одна строка = один аккаунт в одном временном окне**.

| Столбец | Обязателен | Допустимые значения |
|---|---|---|
| `account_id` | да | псевдоним: латиница, цифры, `_`, `.`, `-`, 1–64 символа. Адреса почты, телефоны, ФИО и т. п. **не допускаются** (символы `@`, пробелы, кириллица отклоняются) |
| `window` | да | неотрицательное целое **или** дата `ГГГГ-ММ-ДД`; окна упорядочиваются по возрастанию и считаются соседними (пропуски номеров допустимы, но получают предупреждение) |
| признаки (любые имена) | ≥ 4, ≤ 64 | числа; пустая ячейка, `NA`, `NaN`, `null` — пропуск; десятичная точка (при `;`-разделителе допускается запятая); `inf` и значения по модулю > 10⁹ отклоняются |
| `label` | нет | `0`/`1`. Используется **только** для оценки качества после анализа («метки набора»), алгоритму не передаётся |

Имя признака: `[A-Za-z][A-Za-z0-9_]{0,39}`. Имена `account_id`, `window`, `label` зарезервированы. Разделитель — запятая или точка с запятой (определяется по заголовку); кодировка UTF-8 (BOM допускается).

## Ограничения (настраиваются переменными окружения)

10 МБ, 200 000 строк, 20 000 аккаунтов, 200 окон, 64 признака; минимум 10 различных окон; пара (`account_id`, `window`) встречается не более одного раза.

## Проверки при загрузке

Расширение `.csv`; размер (чтение обрывается при превышении); отсутствие нулевых байтов; кодировка; уникальность и допустимость имён столбцов; тип и диапазон каждого значения; формат `account_id` и `window`; дубликаты пар; число окон/аккаунтов/строк. Предупреждения (не блокируют): окна с < 50 аккаунтов, признаки с > 50 % пропусков, постоянные признаки, разрывы номеров окон. Данные только разбираются, никогда не исполняются.

## Что считается окном

Окно — интервал времени, за который агрегированы признаки аккаунта (например, сутки или неделя). Агрегацию из сырых событий пользователь выполняет заранее; прототип её не делает. Первые окна («начальный период») используются только для обучения модели и калибровки порога.

## Конфиденциальность

Не загружайте персональные и медицинские данные без подтверждённых прав и обезличивания. В демонстрации используются только синтетические данные.
